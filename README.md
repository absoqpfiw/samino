# Samino — Android Prototype

هذا مشروع أولي لتطبيق اجتماعي باسم Samino، مبني بـ Kotlin + Jetpack Compose.

## التشغيل
1. افتح المجلد في Android Studio حديث.
2. انتظر مزامنة Gradle.
3. شغّل التطبيق على محاكي أو هاتف Android.

## الموجود في النسخة الأولى
- الصفحة الرئيسية والمنشورات
- المجتمعات
- الدردشات
- الملف الشخصي
- إنشاء منشور محليًا
- واجهة عربية واتجاه RTL مناسب

## المرحلة التالية المقترحة
ربط Firebase لإضافة تسجيل الدخول، قاعدة بيانات المنشورات والمجتمعات، رفع الصور، الدردشة الحقيقية، الإشعارات، والتبليغ والحظر.
